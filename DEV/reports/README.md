# Tracked DEV Reports

This directory contains tracked engineering and task reports for the OTG Analytics repository.

Reports numbered 001 and above are authoritative GitHub-visible reports. Each task uses `NNN_TASK_NAME/REPORT.md`.

Reports are written after the implementation commit so they can contain the exact implementation SHA. A completed task normally produces an implementation commit followed by a report-only commit. Report-only commits must not contain application changes.

Reports must never contain secrets. A report PASS does not imply production deployment. When no real browser validation occurred, `VISUAL_VALIDATION` remains `HUMAN_VALIDATION_REQUIRED`.

Historical reports created before this system may remain in the external DEV archive and are not required to be migrated.
